# YoutubeKitをスマホだけで使う

対象: v0.3.1 / 2026-10-29

## Google接続後に開けなくなった場合

v0.3.0のアプリ保存処理に不具合があり、Google接続後や再読み込み時に `ERR_FAILED` になる場合がありました。v0.3.1で修正しています。

Safariで [復旧ページ](https://youtube-kit.tokana2212.workers.dev/recover) を開き、「修正版を適用して開く」を押してください。キュー・非表示・設定・Google接続は削除しません。PCなど別のブラウザでも発生している場合は、そのブラウザから同じ操作を行います。

## 最初の設定

1. iPhoneのSafariで [YoutubeKit](https://youtube-kit.tokana2212.workers.dev/) を開きます。PCの電源は不要です。
2. Safariの共有メニューから「ホーム画面に追加」を選び、追加します。「Webアプリとして開く」がある場合はオンにします。iOSのバージョンによりメニューの場所・表示は異なります。
3. ホーム画面のYoutubeKitアイコンから開きます。
4. 「Googleアカウントに接続」を押し、設定済みの自分のアカウントで接続します。Safariで先に接続していても、ホーム画面版で接続を求められた場合はそちらでも接続してください。
5. アプリへ戻ったら右上の更新ボタンを押します。公開環境の初回は登録チャンネルと動画を取得します。途中で一部チャンネルが失敗した場合は、設定からチャンネル名・理由を確認できます。

Google設定の追加作業とCloudflareへのSecrets登録は完了しています。接続できない場合は [セットアップのエラー対処](セットアップ.md#6-接続期限エラー) を確認してください。GoogleのExternal/Testing設定のまま使う場合は、通常7日ごとの再接続が必要になることがあります。

## 動画を選んで再生する

1. サムネイルをタップしてキューへ追加します。表示された数字が再生順です。もう一度押すと削除します。
2. 下のキューを開き、順番を確認・変更します。
3. 「再生開始」を押します。Safariが自動再生を止めた場合は、案内に従いプレーヤーの再生ボタンを押してください。
4. 選んだ最後の動画で再生が終了します。

表示密度・短い動画の除外時間は歯車から変更します。画面ロックや他のアプリへの移動中の連続再生は保証していません。アプリが非表示になると一時停止します。

## 保存と通信

- PCを閉じても、外出先の携帯回線やWi-Fiから公開URLを使用できます。
- キュー・非表示・表示設定は、このブラウザ／ホーム画面アプリの端末内へ自動保存します。端末間同期は後回しです。
- PCのローカル版、公開版、別のブラウザの保存キューは自動移行しません。
- ブラウザのサイトデータを削除すると、保存キューや設定も消えます。
- 一度保存したアプリ本体は通信できないときも起動できます。動画の情報取得・サムネイル表示・Google接続・再生には通信が必要です。動画をダウンロードする機能はありません。

## アプリを更新する

動画一覧の右上の更新は、新着動画の取得です。アプリ本体の更新とは別です。

1. 再生を終了し、歯車から「アプリの更新を確認」を押します。
2. 新しい版があるという案内が出たら設定を閉じます。
3. 一覧上部の「アプリを更新」を押します。再読み込み後も保存したキュー・非表示・設定は維持します。

新しい版が見つかっても、再生途中に勝手に再読み込みしません。開き直したときに自動で検出する場合もあります。

## 今回お願いする実機確認

公開サーバーとデスクトップでのPWA保存・更新は確認しました。iPhone/iPad実機はまだ確認していないため、次を試してください。

1. ホーム画面から開いてGoogle接続、登録チャンネル取得、サムネイルのタップを試します。
2. 2本をキューに入れ、順番に再生されて最後で止まることを確認します。
3. アプリを閉じて開き直し、キュー・非表示・表示密度が戻ることを確認します。
4. PCを閉じ、iPhoneのWi-Fiを切って携帯回線から開き、更新・再生できることを確認します。
5. 画面ロック・別アプリへ移動・元へ戻る操作で、停止と再開の案内が分かるか確認します。

問題があれば、使ったiPhoneとiOSのバージョン、Safariかホーム画面版か、行った操作、表示された文言を教えてください。秘密値や認証URL全体は送らなくて大丈夫です。

参照: [Apple公式「WebサイトをiPhoneのアプリとして使う」](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)。
