# YoutubeKitをスマホだけで使う

対象: v1.0.0 / 2026-10-29

## Google接続後に開けなくなった場合

v0.3.0のアプリ保存処理に不具合があり、Google接続後や再読み込み時に `ERR_FAILED` になる場合がありました。v0.3.1で修正しています。

Safariで [復旧ページ](https://youtube-kit.tokana2212.workers.dev/recover) を開き、「修正版を適用して開く」を押してください。キュー・非表示・設定・Google接続は削除しません。PCなど別のブラウザでも発生している場合は、そのブラウザから同じ操作を行います。

## 最初の設定

1. iPhoneのSafariで [YoutubeKit](https://youtube-kit.tokana2212.workers.dev/) を開きます。PCの電源は不要です。
2. Safariの共有メニューから「ホーム画面に追加」を選び、追加します。「Webアプリとして開く」がある場合はオンにします。iOSのバージョンによりメニューの場所・表示は異なります。
3. ホーム画面のYoutubeKitアイコンから開きます。
4. 「Googleアカウントに接続」を押し、設定済みの自分のアカウントで接続します。Safariで先に接続していても、ホーム画面版で接続を求められた場合はそちらでも接続してください。
5. アプリへ戻ったら右上の更新ボタンを押します。公開環境の初回は登録チャンネルと動画を取得します。途中で一部チャンネルが失敗した場合は、設定からチャンネル名・理由を確認できます。

Google設定の追加作業とCloudflareへのSecrets登録は完了しています。接続できない場合は [セットアップのエラー対処](セットアップ.md#6-接続期限エラー) を確認してください。GoogleのExternal/Testing設定のまま使う場合は、通常7日ごとの再接続が必要になることがあります。

## 動画を選んで再生する

1. サムネイルをタップしてキューへ追加します。表示された数字が再生順です。もう一度押すと削除します。
2. 下のキューを開き、順番を確認・変更します。
3. 「再生開始」を押します。Safariが自動再生を止めた場合は、再生画面の「再開」を押してください。埋め込みプレーヤーのシークバーも使えます。通常はプレーヤー直下のアイコンで、前の動画、10秒戻る、再生・一時停止、10秒進む、次の動画を操作してください。
4. 選んだ最後の動画で再生が終了します。

表示密度・短い動画の除外時間は歯車から変更します。画面ロックや他のアプリへの移動中の連続再生は保証していません。アプリが非表示になると一時停止します。

## 概要欄・高評価・コメント

- 再生画面で「概要欄」を開きます。青い時刻を押すと、概要欄を開いたまま再生位置が移動します。最後まで読んだら本文末尾の「概要欄を閉じる」から見出しへ戻れます。
- 初回は更新したプライバシーポリシーを確認し、「同意して使う」を押します。続いて再生画面または設定で「高評価・コメントを許可」を選び、Googleで追加権限を許可します。追加同意のあと、キューから再生を開き直せます。
- 表示されたYouTubeチャンネルを確認します。「高評価」はYouTubeに反映され、「高評価済み」を再度押すと解除されます。動画を再び開くと、YouTube上の変更を読み直します。
- 「コメント」から公開コメントを投稿し、「コメント編集」から最新の本文を確認して編集・削除します。対象はYouTubeKitから投稿した1動画1件のトップレベルコメントです。公式アプリやWebで新規投稿したコメントは管理対象外です。

「コメント確認・復旧」が表示されたら、まず別の画面で処理中でないか確認し、画面の「コメントの状態を再確認」を使います。投稿結果が不明な場合は、同じチャンネルのYouTubeコメント履歴で対象動画のコメントを確認してください。投稿が残っていれば、必要に応じてYouTubeから削除します。そのうえでアプリの「管理状態をリセット」を選べば、再投稿できます。

## 保存と通信

- PCを閉じても、外出先の携帯回線やWi-Fiから公開URLを使用できます。
- キュー・非表示・表示設定は、このブラウザ／ホーム画面アプリの端末内へ自動保存します。端末間同期は後回しです。
- PCのローカル版、公開版、別のブラウザの保存キューは自動移行しません。
- ブラウザのサイトデータを削除すると、保存キューや設定も消えます。
- 一度保存したアプリ本体は通信できないときも起動できます。動画の情報取得・サムネイル表示・Google接続・再生には通信が必要です。動画をダウンロードする機能はありません。

## 動画の表示サイズ

動画と上下の再生操作は、縦横回転や表示領域の変化に合わせて配置します。画面の高さが小さい場合は、スクロールして再生操作を表示できます。

## シアターモードと全削除

1. 歯車の設定の「シアターモード」で明るさを1〜100%から選びます。初期値は20%、変更は端末内に自動保存します。キューの再生中も設定を開いて変更できます。
2. 再生を開始し、画面右上の設定の右にあるシアターアイコンを押します。確認画面は出ず、ページ全体へ明るさが反映されます。
3. モード中は左スワイプで10秒戻し、右スワイプで10秒進めます。トリプルタップで再生・一時停止を切り替えます。それ以外のタップ・スワイプでは背後を操作しません。準備中・エラー中・キュー完了後は再生や位置変更を行いません。
4. シアターボタンの位置を正確にタップするか、画面を動かさず3秒長押しすると解除します。

アプリは映像を消したり本体の輝度を変えたりしません。Safariのアドレスバー、通知、OSの端からのジェスチャーはアプリのガード対象外です。電池消費を抑えるには、[Appleの手順](https://support.apple.com/ja-jp/109351)で本体の明るさも下げてください。

シアターで動画を再生すると、標準のScreen Wake Lock APIで画面の自動ロックを防止します。一時停止、再生終了、シアター解除の後は端末の自動ロック設定が適用されます。シアターのまま再生を再開すると、自動ロック防止が再び有効になります。低電力状態や端末の制約で利用できない場合があります。本体をロックした場合や別のアプリへ移った場合のバックグラウンド再生には対応しません。iPhoneでのジェスチャー・自動ロック防止・電池消費の実測は別途確認が必要です。

キューの全削除は、下のバーの再生開始ボタン左側にあるごみ箱からできます。確認でキャンセルした場合はキューを維持します。

## アプリを更新する

動画一覧の右上の更新は、新着動画の取得です。アプリ本体の更新とは別です。

1. 再生を終了し、歯車から「アプリの更新を確認」を押します。
2. 新しい版があるという案内が出たら設定を閉じます。
3. 一覧上部の「アプリを更新」を押します。再読み込み後も保存したキュー・非表示・設定は維持します。

右上の更新ボタンでも、新着とアプリの新版を確認できます。初期設定では30分以上アプリを離れてから開くと、自動で確認します。設定の「アプリとホーム画面」で間隔の変更やオフを選べます。

新しい版が見つかっても、再生途中に勝手に再読み込みしません。開き直したときに自動で検出する場合もあります。

## v2.0.0 の実機確認

iPhoneまたはiPadのSafariとホーム画面版で、概要欄の開閉、全角タイムスタンプ、一時停止中の移動と再生位置の保存、キュー最後の動画終了後の移動を確認します。コメント入力中は、ソフトウェアキーボードを表示したまま投稿・キャンセルへ移動できるか確認します。追加同意と実際の高評価・コメント操作を試す場合は、公開してよいテスト用の動画とチャンネルを使用してください。

## 今回お願いする実機確認

公開サーバーとデスクトップでのPWA保存・更新は確認しました。iPhone/iPad実機はまだ確認していないため、次を試してください。

1. ホーム画面から開いてGoogle接続、登録チャンネル取得、サムネイルのタップを試します。
2. 2本をキューに入れ、順番に再生されて最後で止まることを確認します。
3. アプリを閉じて開き直し、キュー・非表示・表示密度が戻ることを確認します。
4. PCを閉じ、iPhoneのWi-Fiを切って携帯回線から開き、更新・再生できることを確認します。
5. 画面ロック・別アプリへ移動・元へ戻る操作で、停止と再開の案内が分かるか確認します。

問題があれば、使ったiPhoneとiOSのバージョン、Safariかホーム画面版か、行った操作、表示された文言を教えてください。秘密値や認証URL全体は送らなくて大丈夫です。

参照: [Apple公式「WebサイトをiPhoneのアプリとして使う」](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)。
